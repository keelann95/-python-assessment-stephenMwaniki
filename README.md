## How to Run

Install dependencies first:
```bash
pip install -r requirements.txt
```

Then run any file with:
```bash
python3 filename.py
```

Note: `task8_net_salary_calculator.py` and `task9_disease_diagnosis.py` prompt
for user input in the terminal.
